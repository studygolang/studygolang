## 修复内容

### 1. 路由注册顺序修复 ✅

**文件**: `cmd/studygolang/main.go`

**修复前**:
```go
frontG := e.Group("")          // 先注册,拦截所有路由
controller.RegisterRoutes(frontG)

adminG := e.Group("/admin")
admin.RegisterRoutes(adminG)

appG := e.Group("/app")
app.RegisterRoutes(appG)

apiG := e.Group("/api/v1")     // 后注册,被拦截
api.RegisterRoutes(apiG)
```

**修复后**:
```go
// 先注册有前缀的路由
apiG := e.Group("/api/v1")
api.RegisterRoutes(apiG)

appG := e.Group("/app")
app.RegisterRoutes(appG)

adminG := e.Group("/admin", pwm.NeedLogin(), pwm.AdminAuth())
admin.RegisterRoutes(adminG)

// 最后注册无前缀的前端路由（兜底）
frontG := e.Group("")
controller.RegisterRoutes(frontG)
```

## 剩余问题分析

### 🟡 P1 - 元素定位问题 (7个测试失败)

**问题**: 测试用例的元素选择器不够精确

**示例**:
- 用户卡片选择器: `a[href^='/user/']` 可能匹配多个元素
- Tab 选择器: `[role='tab']` 可能匹配多个 Tab

**建议修复**:
1. 为关键元素添加 `data-testid` 属性
2. 使用更精确的选择器
3. 使用 `.first()` 或 `.nth()` 明确指定元素

**示例修复**:
```typescript
// 修复前
const userCards = page.locator("a[href^='/user/']")

// 修复后
const userCards = page.locator("[data-testid='user-card']")
// 或
const firstUserCard = page.locator("a[href^='/user/']").first()
```

### 🟡 P2 - 错误提示文案不一致 (2个测试失败)

**问题**: 测试期望 "用户未找到|用户不存在|404",实际提示可能不同

**建议修复**:
1. 统一所有页面的错误提示文案
2. 或更新测试用例匹配实际文案
