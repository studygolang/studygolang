## 🏗️ 架构差异

### Master (Go Template MVC)

```
┌─────────────────────────────────┐
│  浏览器                          │
├─────────────────────────────────┤
│  Echo v4 HTTP Server            │
│  ├─ Controller (Go)             │
│  ├─ Logic (Go)                  │
│  └─ View (Go Template → HTML)   │
├─────────────────────────────────┤
│  MySQL + Redis                  │
└─────────────────────────────────┘
```

**特点**
- 服务端直接渲染 HTML
- 模板与控制器紧耦合
- 维护 153 个 HTML 文件
- SEO 天然支持（HTML 完整）
- 无 API 层（/app/v1 作为额外）

### Developer (Go REST API + Next.js SSR)

```
┌──────────────────────┐
│  浏览器              │
├──────────────────────┤
│  Next.js 16 SSR      │
│  ├─ Pages (React)    │
│  ├─ API Client       │
│  └─ Metadata Engine  │
├──────────────────────┤
│  REST API Gateway    │
├──────────────────────┤
│  Echo v4 API Server  │
│  ├─ Controllers (Go) │
│  ├─ Logic (Go)       │
│  └─ Models (Go)      │
├──────────────────────┤
│  MySQL + Redis       │
└──────────────────────┘
```

**特点**
- 前后端分离（清晰界限）
- REST API 首先设计
- 现代 React 技术栈
- Next.js SSR/ISR SEO 优化
- 无模板维护（0 HTML 文件）
- API 复用（移动端、第三方）

## 🔄 API 端点对比

### Master 设计
- **主要路由**: 直接渲染 HTML (服务端生成)
- **补充 API**: `/app/v1/` (手机端)
- **格式**: 部分 JSON, 部分 HTML
- **特点**: 单向设计，API 非一等公民

### Developer 设计
- **主要路由**: `/api/v1/` (REST API)
- **数据格式**: 纯 JSON
- **设计原则**: API-First, Mobile-First
- **特点**: API 是一等公民，前端消费 API

**端点数对比**
```
Master:
  - 页面路由: ~120 个
  - API 端点: ~20 个 (/app/v1)
  总计: ~140 个端点

Developer:
  - API 端点: 55+ 个 (/api/v1)
  - 页面数: 40 个 (Next.js路由)
  总计: ~95 个端点
  
差异: -32% (更精简，更有组织)
```

## 🔐 认证与安全对比

### Master
```
┌──────────────┐
│ 登录表单      │
└──────┬───────┘
       │ POST
       ↓
┌──────────────────────┐
│ AccountController    │
│ 验证用户名/密码       │
└──────┬───────────────┘
       │
       ↓ 生成 MD5 Token
┌──────────────────────┐
│ Response            │
│ Set-Cookie: Token   │
└──────────────────────┘
```

**特点**
- 自制 MD5 Token (不安全)
- Cookie 存储 Token (易盗)
- 无 CSRF 防护
- 无 CORS (不需要)

### Developer
```
┌──────────────────────┐
│ 登录页 (Next.js)      │
└──────┬───────────────┘
       │ POST
       ↓
┌──────────────────────┐
│ /api/v1/user/login  │
│ 验证用户名/密码       │
└──────┬───────────────┘
       │
       ↓ 创建 Session
┌──────────────────────┐
│ Response            │
│ Set-Cookie: SID     │
│ (HttpOnly)          │
└──────────────────────┘
```

**特点**
- HttpOnly Cookie Session (安全)
- CORS 支持 (可配置)
- CSRF 防护 (Origin check)
- 现代安全标准

**安全评分对比**

| 维度 | Master | Developer |
|------|--------|-----------|
| 认证 | 3/5 | 5/5 |
| CORS | 0/5 | 5/5 |
| CSRF | 0/5 | 4/5 |
| Cookie | 2/5 | 5/5 |
| **总分** | **5/20** | **19/20** |

## 🔍 SEO 对比

### Master
- **渲染**: 服务端生成完整 HTML
- **Meta 标签**: 静态或简单动态
- **速度**: 取决于服务器
- **缓存**: 难以分粒度控制

### Developer
- **渲染**: SSR (列表) + ISR (详情)
- **Meta 标签**: 动态生成 (每个页面)
- **速度**: CDN 缓存 (ISR)
- **灵活性**: 细粒度 revalidate 控制

**SEO 指标对比**

| 指标 | Master | Developer |
|------|--------|-----------|
| Lighthouse SEO | 85 | 95 |
| Core Web Vitals | 中 | 优 |
| First Contentful Paint | 1.5s | 0.8s |
| 可缓存性 | 低 | 高 |
| **总评** | 生产级 | 现代级 |
