## BlockNote 特性

### 核心功能
- **块编辑器**: 每个段落、标题、列表项都是一个独立的块
- **拖拽排序**: 鼠标悬停显示拖拽手柄,可以拖拽重新排序
- **斜杠命令**: 输入 `/` 显示命令菜单,快速插入各种块类型
- **Markdown 支持**: 自动转换 Markdown 语法,支持导入导出

### 支持的块类型
- 段落、标题 (1-3)、无序列表、有序列表
- 待办事项、引用、代码块、表格
- 图片、分割线

### 格式化选项
- 粗体 (Ctrl/Cmd + B)、斜体 (Ctrl/Cmd + I)
- 代码 (Ctrl/Cmd + E)、删除线
- 链接、颜色和背景色

## 使用方式

1. 访问 `/publish` 页面
